# Gauteng Housing Forum

A collaborative platform dedicated to addressing housing challenges and opportunities in the Gauteng Province.

## About

The Gauteng Housing Forum brings together stakeholders, community leaders, and housing professionals to share knowledge, discuss innovations, and develop sustainable housing solutions for the province.

## Features

- **Homepage**: Professional landing page showcasing the forum's mission and vision
- **About Section**: Detailed information about the organization and its core values
- **Events**: Showcase upcoming housing-related events and roundtables
- **Resources**: Directory of reports, publications, and support services
- **Contact**: Easy way for visitors to get in touch

## Getting Started

### View the Website

1. Open `index.html` in your web browser
2. Navigate through the different sections using the menu
3. Fill out the contact form to get in touch

### File Structure

```
gauteng-housing-forum/
├── index.html       # Main homepage
├── styles.css       # Stylesheet with responsive design
├── script.js        # Interactive features and animations
└── README.md        # This file
```

## Customization

You can easily customize:

- **Colors**: Modify the gradient colors in `styles.css` (currently using blue and purple)
- **Content**: Update text, events, and resources in `index.html`
- **Contact Info**: Replace placeholder email and phone with actual contact details
- **Events**: Add or remove event cards in the Events section
- **Social Links**: Update social media URLs in the footer

## Deployment

### Option 1: GitHub Pages

1. Go to repository Settings → Pages
2. Select "Deploy from a branch"
3. Choose the `main` branch
4. Your site will be available at `https://senaoaneonline.github.io/gauteng-housing-forum/`

### Option 2: Other Hosting

You can deploy these files to any web hosting service (Netlify, Vercel, etc.)
